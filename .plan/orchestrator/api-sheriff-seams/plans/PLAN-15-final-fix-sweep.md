## Objective

PLAN-14 shipped the response-side classification of the back-channel exchange and most of its fixture and name work, and its analysis left what is this repository's own: a framed test name the spec itself named and a set of siblings, a cause chain `exchange` still chains unmapped, a fixture whose `close()` can skip its own shutdown, tests that cannot fail for the behaviour they are cited for, a Javadoc sentence that cites a test for a case it does not hold, and a Quarkus dev-mode boot failure nobody has read. This plan closes those, so that nothing that ships in 0.9.10 rests on a name, a sentence or a test the code does not bear out and the one failure the lane could not explain is either shown to be environmental or fixed. No public API is added, and the default behaviour of every class named here does not change except where a decision below says so.
